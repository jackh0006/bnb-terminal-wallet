# Contributor Covenant Code of Conduct

We are committed to a welcoming, harassment-free community. Be respectful, assume good faith, and do not share sensitive wallet material or personal data.

Unacceptable conduct includes harassment, threats, publishing private information, or submitting recovery phrases, private keys, passwords, API keys, or sensitive transaction data. Report concerns privately using the contact in SECURITY.md. Maintainers may remove contributions or participation that violate this code.

This policy follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
