# Governance

BNB Terminal Wallet is maintained by Jack Hudson. The maintainer is responsible for releases, security-response coordination, dependency updates, and accepting or declining contributions.

Changes affecting key handling, encryption, transaction construction, RPC trust, or release automation require documented threat-model consideration, passing CI, and maintainer review. Breaking security changes receive a new major version where practical.

Community members are expected to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Security reports follow [SECURITY.md](SECURITY.md), not public issues.
