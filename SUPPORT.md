# Support

For safe usage questions, start with the README and the in-app safety guide. For reproducible defects, use the GitHub bug-report template and include only non-sensitive details.

For security vulnerabilities, use the private reporting path in [SECURITY.md](SECURITY.md). Never send recovery phrases, private keys, passwords, API keys, keystores, or sensitive transaction details through issues, email, or chat.

This project does not provide custody, investment advice, transaction recovery, or support for lost secrets.
